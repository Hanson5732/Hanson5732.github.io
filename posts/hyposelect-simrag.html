Published: October 2025 · IEEE ICCEIC 2025 · Retrieval-Augmented Generation

HypoSelectSimRAG: Enhancing Answer Accuracy in RAG via Multi-Path Self-Consistent Query Translation

By Zhi Chen, Hanqi Huang (黄瀚祺), Junjie Wu, et al.

1. The Problem with Classical RAG and HyDE

Standard Retrieval-Augmented Generation (RAG) relies on dense vector search directly computed from the raw user query. However, users frequently express complex informational needs using colloquial, incomplete, or polysemous phrasing. When this happens, the query embedding deviates significantly from the document embedding space, yielding noisy retrieved contexts and severe hallucinations in LLM responses.

Hypothetical Document Embeddings (HyDE) attempted to resolve this by asking an LLM to generate a hypothetical answer document before retrieval. However, a single hypothetical document carries high stochastic variance: if the LLM hallucinates in the hypothetical document, the retrieval system is guided in the completely wrong direction.

2. Our Approach: HypoSelectSimRAG

To break the single-path dependency while preserving semantic grounding, we proposed HypoSelectSimRAG. Our core architecture consists of three components:

  • Multi-Path Generation: We design two prompting formulations (Few-Shot Prompting and Question-Classification Prompting) under dual decoding temperatures ($T=0.1$ for deterministic focus, $T=1.1$ for exploratory diversity), creating 4 candidate hypothetical documents.
  • Candidate Selection: We designed and benchmarked 5 candidate selection methods: Self-Consistency Voting, Scoring, Summary Aggregation, Average Vector, and Best Vector.
  • Similarity-Aligned Dense Retrieval: The Best Vector candidate—the hypothetical document with the maximum cosine similarity to the original query—is fed to dense embedding retrieval to query the vector store.

3. Experimental Results on RAGAS Benchmark

We evaluated the framework on the standardized rag-dataset-1200 benchmark using RAGAS (Retrieval Augmented Generation Assessment) across Factual Correctness, Answer Semantic Similarity, and Context Relevance.

Method Factual Correctness ↑ Answer Semantic Similarity ↑ Context Relevance ↑
Naive RAG 0.5257 0.8124 0.5620
HyDE 0.6178 0.8492 0.6350
HypoSelectSimRAG (Ours) 0.6910 0.8872 0.7180

As demonstrated above, HypoSelectSimRAG achieved an impressive +31.4% improvement in Factual Correctness over standard RAG, and substantially exceeded single-path HyDE.

4. Implementation & Availability

The pipeline was implemented using Python and the LangChain framework, monitored through LangSmith for token tracing, and validated on extensive test sets.
